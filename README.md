# Controle Financeiro com Dashboard no Excel

Este projeto apresenta um dashboard financeiro desenvolvido no Microsoft Excel, com o objetivo de acompanhar receitas, despesas, saldo final, maiores gastos e distribuição dos valores por categoria e por mês.

## Visual do Dashboard

![Dashboard Financeiro](imagens/dashboard-financeiro.png)

## Objetivo do Projeto

O objetivo deste projeto é transformar uma base simples de movimentações financeiras em um painel visual e interativo, facilitando a análise do orçamento ao longo dos meses.

Com este dashboard, é possível visualizar:

- Receita total
- Despesas totais
- Saldo final
- Maior despesa
- Média de despesas
- Despesas por categoria
- Entradas x saídas por mês
- Valores classificados por análise
- Filtros interativos por mês, tipo e categoria

## Estrutura da Base de Dados

A base financeira contém as seguintes colunas:

- Data
- Mês
- Tipo
- Categoria
- Descrição
- Valor
- Análise

## Análises Criadas

### Despesas por Categoria

Permite identificar quais categorias representam os maiores gastos dentro do período analisado.

### Entradas x Saídas por Mês

Compara mensalmente o total de receitas e despesas, ajudando a entender a evolução do saldo.

### Valores por Análise

Classifica os valores em níveis como Valor Alto, Valor Médio e Valor Baixo, facilitando a leitura dos principais impactos financeiros.
